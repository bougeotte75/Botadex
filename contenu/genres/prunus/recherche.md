# Cerisier, prunier (*Prunus*) — dossier de recherche

Tout ce qui a été collecté sur le genre, sourcé, avant sélection pour la fiche jeu (`fiche.yaml`).

**Format d'une note** (le script `scripts/verifier_contenu.py` s'appuie dessus) :

```
### PRU-001 · à trier
Ce que dit la source, reformulé avec nos mots (citation exacte courte seulement si la formulation compte).
- Source : [Titre de la page](https://…), consulté le AAAA-MM-JJ
- Remarque : facultatif (pourquoi écartée, contradiction avec une autre note…)
```

- Identifiant : `PRU-` + trois chiffres, jamais réutilisé, même pour une note supprimée.
- Statut : `à trier` · `retenu` · `écarté` · `à vérifier`.
- Une note = une seule information. Une note par source quand deux sources disent la même chose (c'est ce qui permet de recouper).
- Les notes sur une espèce précise vont dans la rubrique « Espèce — *Nom scientifique* ».
